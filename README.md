# 智慧运营 · 供应链数据驾驶舱与经营分析看板体系 — Web 原型

纯静态原型，**零依赖、无构建、无外部字体/图表库**。直接双击 `index.html` 即可在浏览器中打开。

> 依据文档：`../智慧运营优化_PRD_v1.0.md`（产品需求，唯一功能基准）+ `../原型设计说明.md`（需求→角色→流程→IA→页面结构→UI 的设计推导）。
> **视觉与版式基准（按页面）**
> - **F5 采购数据报表**：`../采购报表总览.png` / `../采购报表明细.png`——页签（局级总览 / 明细）、两套筛选字段、两级表头列集、
>   明细 13 列与 1000 行规模逐项对齐；下钻交互沿用 PRD AC25。
> - **F4 物资数据报表 / F6 分供商数据报表 / F7 资产数据报表**：无产品截图，列序 / 列名 / 页签 / 筛选字段以 **Axure 导出稿**
>   （`物资数据报表.html` / `分供商数据报表.html` / `资产数据报表.html`，路径见下）为准，版式沿用 F5。
> - **F2 局驾驶舱**：`../局驾驶舱页面1.png`——区块构成、文案与数值逐项对齐；交互则沿用 Axure 导出稿的交互原理（页签互斥、指标卡联动、下钻、列设置、轮播）。
> - **采购管理看板**：`../采购管理看板.png`（页内标题「指标总览-采购」，1912×2164）——逐项对齐。

>   顶栏的**内容**按产品实际界面对齐：品牌「中建八局 │ 数字供应链」+ 7 个模块「首页 · 智选资源 · 智慧采购 · 智能物管 · 智慧运营 · 八局甄选 · 系统管理」，当前模块为深色填充块；
>   **顶栏与面包屑整体吸顶**（面包屑 sticky 于 56px 之下，蓝带 background-attachment:fixed 保证底色不断层）
>   （各带图标）+ 全局菜单搜索框。窄屏（≤1560px）自动隐藏搜索框并压缩间距。

## 深链接参数

| 参数 | 说明 | 示例 |
|---|---|---|
| `page` | 页面：`screen` / `cockpit` / `project` / `material-board` / `purchase-board` / `supplier-board` / `report` / `compliance` | `?page=cockpit` |
| `org` | 组织视角（R1 权限过滤起点），缺省为「局总部」 | `?page=cockpit&org=二公司` |
| `ds` | 数据报表数据集：`purchase` / `material` / `supplier` / `asset` | `?page=report&ds=material` |
| `view` | 采购 / 物资报表页签：`overview`（局级总览，默认）/ `detail`（明细）；页签在页内切换，URL 同步但不重载 | `?page=report&ds=material&view=detail` |
| `project` | 项目驾驶舱锁定项目名称 | `?page=project&project=山海境小区项目施工总承包` |
| `pcode` | 同上，按项目编码定位 | `?page=project&pcode=…` |

## 演示路径建议

1. **一屏入口**：`?page=screen` → 本季度 / 本月度 / 本年度切换、实时时钟、采购动态 5 秒轮播、右下分供商规模切「在库 / 优秀 / 新进 / 履约分供商」看渐变柱状联动
2. **局级驾驶舱**：`?page=cockpit&view=overview` → 采购金额构成饼图 → 物资进场数据切「高级筛选」/ 查询 / 清空 → 物资小类 4 卡点击切换 → 区块标题右侧箭头收起/展开整段
3. **采购管理看板**：`?page=purchase-board` → 点指标卡联动下方页签与红色趋势图（双向）→ 切换日期粒度 日/月/季/年 → 查看二级单位明细与招采分析六阶段；左侧「采购管理 / 物资管理 / 分供商管理 / 资产管理」四个父级点击可收起/展开各自的两个子菜单（父级本身不导航）
3b. **物资管理看板**：`?page=material-board` → 点指标卡 / 页签双向联动重绘红色趋势 → 二级单位排行与分页 → 六项降本切卡换折线 → 降本明细「展开」更多筛选 / 「降本金额正负」切全部·正数·负数（就地过滤）/「降本明细项查询」复选（默认全选，取消即按勾选范围取数）/「设置列」勾上三级单位或项目名称把行粒度下沉到项目 → 废旧物资处理分组柱对比
3d. **筛选与口径**：驾驶舱与看板（F2 / 采购管理看板 / 物资管理看板）的筛选字段是真下拉/真输入框；查询/清空/重置 读取实际取值，并在操作区左侧就地反馈「已按 N 个条件查询」。hover 或点击任意指标卡显示**口径气泡**（指标定义 / 统计口径 / 数据来源；口径未明确的按 PRD 标注「待确认」，不臆造规则）
3e. **分供商管理看板**：`?page=supplier-board` → 8 张指标卡看同比与上年度 → 各区块的筛选/图表 → hover 指标看口径
3g. **资产管理看板**：`?page=asset-board` → 指标卡/页签双向联动 → 二级单位明细「列设置」改列 → 资产类别构成饼图与双轴组合图
3. **下钻链路（UF2）**：F5 **总览**页签点单位名逐级下钻（二级→三级→项目），「返回上一级」可回退，下级合计恒等于上级；切到**明细**页签看合同清单（展开筛选 / 列设置 / 翻页）；F3 项目选择器切换锁定项目
4. **宽表列自定义**：任一数据报表 / F3 合同明细 → 「列设置」→ 勾选 + 拖拽排序 → 应用，表头即时变化
5. **合规处置（F8）**：`?page=compliance` → 切页签 → 点指标卡的正常/异常环状图 → 弹出该指标「异常数明细」→ 「推送八局通通知」
6. **权限差异**：同一条链接把 `org` 换成 `二公司` / `三公司`，对比组织树选项、项目选择器、明细行与排名的可见性变化
